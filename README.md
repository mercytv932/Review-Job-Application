Job Application Tracker

A web application built with Vanilla JavaScript that helps users organize and track their job applications throughout the hiring process.

Current Progress

Currently building core application tracking features including:

Adding job applications
Displaying applications dynamically
Deleting applications

Add Applications

Users can add:

Company Name
Position

View Applications

Applications are rendered dynamically to the page using JavaScript DOM manipulation.

Delete Applications

Users can remove applications from the tracker.

Search Applications

Users can search applications by:

Company Name
Position

Search updates in real time as the user types.
